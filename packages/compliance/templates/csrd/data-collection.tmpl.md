## How to use this template

One row per metric. The columns are deliberately the ones an assurance provider
asks for: **who provides the number, from what source, and how would you prove
it**. A metric with no method and no owner is a number you will have to
reconstruct at audit time, which is how disclosures end up being late.

Columns:

- **Metric** — the datapoint name as ESRS 2 states it
- **Value** — the figure for the period
- **Unit** — tonnes, EUR, %, headcount, etc.
- **Method** — how it is calculated, including any standard applied
- **Source system** — where the underlying records live
- **Owner** — the named person accountable
- **Assurance** — whether externally assured
- **Compared to prior year** — and why it moved
