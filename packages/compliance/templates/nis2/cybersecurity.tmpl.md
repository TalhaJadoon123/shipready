## 5. AI-specific cyber risk

Our AI systems add risk categories that did not previously exist:

| Risk | Mitigation |
| --- | --- |
| Unbounded consumption (cost exhaustion) | Per-request token cap, per-user quota, per-endpoint rate limit, monthly spend alarm |
| Prompt injection through tool access | Narrowed tool permissions, delimited inputs, adversarial eval cases |
| Model supply chain (upstream provider) | Provider incident monitoring, fallback provider |
| Data leakage through logs | Prompt and response hashing by default; redaction at the logger |
| Excessive agency in agent tooling | Tool allowlists, workspace-scoped filesystem access |
