# ShipReady Desktop

Launches the ShipReady dashboard locally and opens it in your browser.

This is a **launcher, not an Electron shell**, and that is a deliberate choice
rather than a compromise:

- No 200 MB dependency to download, patch or keep up to date.
- The UI is the same server-rendered dashboard as the hosted version. An
  Electron shell would be a second implementation, and a second implementation
  drifts.
- It works anywhere Node 20.10+ runs: Windows, macOS, Linux.

If you need a signed `.exe`/`.dmg` in a few hundred megabytes with a native
window and no browser chrome, that is a different piece of work and worth doing
only once there is demand for it.

## Run it

From the repository root:

```bash
node apps/desktop/scripts/launch.mjs
```

It will, on first run, build the dashboard, seed demo data, start the server,
wait for it to actually answer, and open your browser at
<http://localhost:3001>.

## Options

```bash
--port 4000    # different port
--no-open      # start the server but do not open a browser
--reset        # wipe the demo snapshot and re-seed from scratch
```

## What you get

The dashboard shows:

- a readiness score and verdict, with the blockers ranked by what they would cost
- a category radar, so you can see whether the low score is one broken area or
  everything
- a trend line across scans, with the "ship it" threshold drawn on
- agent observability: model spend, tokens, errors, per-run traces
- compliance pack status and outstanding gaps
- e-invoice validation history

The demo data is generated by **really scanning** a synthetic repository that
gains one fix per step, so the trend is the scanner's output rather than a
hardcoded array. `--reset` regenerates it from scratch.

## Requirements

Node 20.10 or newer. The dashboard needs `@shipready/core` built, which the
launcher does for you if `packages/core/dist` is missing.
